# Маршрут обновления БД

Программа для определения последовательности обновления сборок программного продукта и требуемых действий по настройке СУБД (Sybase 9.0 / 12 / 16 / 17).

## 📌 Описание

Пользователь вводит текущую версию сборки (например, `4599`), и программа выводит пошаговый маршрут обновления до актуальной версии (`5810`), включая:
- Переходы между версиями
- Требуемые версии Sybase
- Инструкции по созданию DSN
- Предупреждения об установке новых версий СУБД

Поддерживаемые диапазоны сборок: от **1084** до **5810**.

## ▶️ Как запустить

1. Распакуйте архив `UPHelper_d4w.zip`
2. Запустите файл:  
3. Введите номер текущей сборки
4. Нажмите **«Построить маршрут»** или клавишу **Enter**

> 💡 **Java не требуется!** Приложение полностью автономное.

## 🖥️ Управление

- Ввод номера сборки — только цифры
- После ввода можно нажать **Enter** вместо кнопки
- Текст маршрута автоматически прокручивается в начало
